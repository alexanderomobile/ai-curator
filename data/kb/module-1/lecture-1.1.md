# Переменные и типы данных

## О чём лекция

Это первая лекция модуля 1 «Основы Python». Разберём, как Python хранит значения, какие базовые типы встречаются
в любой таблице с данными и как переводить один тип в другой. Всё это понадобится в ДЗ hw1 «Анализ списка покупок»
(методичка guide-1) и дальше в pandas: колонка таблицы в модуле 2 — это набор значений одного типа.

Примеры написаны для Python 3.12. Их удобно запускать в Google Colab, по одной ячейке.

## Переменная — имя для значения

Переменная создаётся присваиванием: слева имя, справа значение. Объявлять тип заранее не нужно, Python определяет
его по самому значению. Это называется динамической типизацией.

```python
city = "Казань"
visits = 3
price = 249.9
is_member = True

print(type(city), type(visits), type(price), type(is_member))
# <class 'str'> <class 'int'> <class 'float'> <class 'bool'>
```

Одно и то же имя можно связать с новым значением другого типа (`visits = "три"`), ошибки не будет, но читать такой
код трудно. Правила для имён: буквы, цифры и `_`, начинать с цифры нельзя, регистр важен (`price` и `Price` —
разные переменные). Руководство по стилю PEP 8 советует для переменных snake_case: `total_price`, `items_count`.

Ключевые слова (`for`, `if`, `class` и другие) именами быть не могут. Имена встроенных функций (`list`, `sum`,
`type`) занять технически можно, но не нужно: после `sum = 10` функция `sum()` в этом ноутбуке перестанет работать.

## Числа: int и float

`int` — целые числа произвольной длины: переполнения, как в некоторых других языках, нет. `float` — числа
с плавающей точкой двойной точности (стандарт IEEE 754). Деление `/` всегда возвращает `float`, а целочисленное
деление `//` и остаток `%` для целых чисел дают `int`.

```python
print(7 / 2)    # 3.5
print(7 // 2)   # 3
print(7 % 2)    # 1
print(2 ** 10)  # 1024
print(0.1 + 0.2)            # 0.30000000000000004
print(round(0.1 + 0.2, 2))  # 0.3
```

Последний результат — не ошибка Python: большинство десятичных дробей нельзя точно записать в двоичном виде.
Поэтому `float` не сравнивают через `==`, а округляют `round()` или сравнивают `math.isclose()`. Учтите, что
`round()` округляет «половинки» к ближайшему чётному: `round(2.5)` даёт `2`, а `round(3.5)` — `4`.

## Строки: str

Строка — неизменяемая последовательность символов в одинарных или двойных кавычках. У строки есть длина,
индексы (с нуля, отрицательные — с конца) и срезы.

```python
item = "  Молоко 3.2% "
clean = item.strip()        # убрать пробелы по краям
print(clean)                # Молоко 3.2%
print(len(clean))           # 11
print(clean[0], clean[-1])  # М %
print(clean[:6])            # Молоко
print("молоко" in clean.lower())  # True
```

Методы строк не меняют исходную строку, а возвращают новую, поэтому результат нужно сохранить: `clean = item.strip()`.
Для вывода чисел в тексте удобнее всего f-строки: `f"Итого: {1234.5:.2f} руб."` даёт `Итого: 1234.50 руб.`

## Логический тип и None

У `bool` два значения: `True` и `False`. Они получаются при сравнениях (`price > 100`) и управляют условиями
(лекция L1.2). `bool` — подкласс `int`, поэтому `True + True` равно `2`, а `sum([True, False, True])` — `2`:
так удобно считать, сколько элементов подошло под условие.

`None` — особое значение «ничего нет», например пропущенное число в данных. Проверяют его через `is`:
`if value is None:`.

## Преобразование типов

Данные из файла, из `input()` или из CSV приходят строками. Прежде чем считать, их нужно преобразовать.

```python
qty = int("3")          # 3
price = float("89.90")  # 89.9
print(qty * price)      # 269.70000000000005
print(round(qty * price, 2))  # 269.7
print(str(42) + " шт.")       # 42 шт.
print(int(7.9))         # 7: дробная часть отбрасывается, а не округляется
print(bool(""), bool("0"))    # False True
float("89,90")          # ValueError: could not convert string to float: '89,90'
```

Запятая как разделитель дробной части — частая проблема русскоязычных выгрузок. Замените её перед
преобразованием: `float("89,90".replace(",", "."))` даёт `89.9`. Строку с дробью сразу в `int` не превратить:
`int("12.5")` вызывает `ValueError`, сначала нужен `float()`.

## Коллекции: list, tuple, dict, set

Короткий обзор, подробнее работаем с ними в L1.2.

```python
basket = ["молоко", "хлеб", "яблоки"]   # list: изменяемый, порядок важен
basket.append("сыр")
point = (55.79, 49.12)                   # tuple: неизменяемый
prices = {"молоко": 89.9, "хлеб": 54.0}  # dict: ключ -> значение
prices["сыр"] = 412.5
categories = {"молочное", "выпечка", "молочное"}  # set: только уникальные

print(len(basket), prices["хлеб"], len(categories))  # 4 54.0 2
```

Начиная с Python 3.7 словарь гарантированно хранит ключи в порядке добавления. У множества порядка нет, поэтому
печатать его и полагаться на порядок не стоит.

## Частые ошибки

- **Сложение строки и числа**: `"Итого: " + 5` даёт `TypeError: can only concatenate str (not "int") to str`.
  Используйте f-строку или `str(5)`.
- **`input()` возвращает строку**: `"2" * 3` — это `"222"`, а не `6`. Сначала `int()` или `float()`.
- **Сравнение `float` через `==`**: `0.1 + 0.2 == 0.3` даёт `False`. Округляйте или используйте `math.isclose()`.
- **Запятая в числе**: `float("94,50")` падает с `ValueError`, нужна замена запятой на точку.
- **Перезапись встроенных имён**: после `list = [1, 2]` вызов `list("abc")` даёт
  `TypeError: 'list' object is not callable`. Переименуйте переменную и перезапустите среду выполнения.
- **Присваивание списка не копирует его**: после `b = a` оба имени указывают на один список, и `b.append(...)`
  меняет и `a`. Копия делается через `a.copy()` или `list(a)`.

## Для продвинутых

- Модель данных Python: всё — объекты, переменная — ссылка на объект. Разберитесь с `id()`, разницей `is` и `==`,
  изменяемыми и неизменяемыми типами: https://docs.python.org/3/reference/datamodel.html
- Почему `0.1 + 0.2` не равно `0.3` и как с этим жить: https://docs.python.org/3/tutorial/floatingpoint.html
- Для денежных расчётов есть `decimal.Decimal`: `Decimal("0.1") + Decimal("0.2") == Decimal("0.3")` даёт `True`.
  Документация: https://docs.python.org/3/library/decimal.html
- Аннотации типов (`price: float = 89.9`) не проверяются при выполнении, но помогают анализаторам вроде mypy
  и basedpyright находить ошибки до запуска.
- В модуле 2 (L2.1) появятся типы NumPy и pandas (`int64`, `float64`, `object`): в отличие от `int` Python,
  целые NumPy имеют фиксированный размер и могут переполняться.
