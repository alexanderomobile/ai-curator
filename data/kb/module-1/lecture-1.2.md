# Условия и циклы

## О чём лекция

Программа редко выполняется строго сверху вниз: нужно выбирать действие (условия) и повторять его для каждой строки
данных (циклы). В этой лекции: `if`/`elif`/`else`, логические операторы, циклы `for` и `while`, `break`
и `continue`, функции `range`, `enumerate`, `zip` и генераторы списков. Понадобятся типы из L1.1, особенно `bool`
и `None`. Всё это напрямую используется в hw1 «Анализ списка покупок» (guide-1).

## Условия: if, elif, else

```python
total = 1840.0

if total >= 2000:
    discount = 0.10
elif total >= 1000:
    discount = 0.05
else:
    discount = 0.0

print(f"Скидка: {discount:.0%}")  # Скидка: 5%
```

Python проверяет условия сверху вниз и выполняет первую подходящую ветку, остальные пропускает. Поэтому порядок
важен: если поставить `total >= 1000` первым, чек на 2500 рублей тоже получит 5 %.

Тело ветки задаётся отступом, PEP 8 рекомендует 4 пробела. Двоеточие в конце строки с `if`, `elif`, `else`, `for`
и `while` обязательно.

Операторы сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`. Сравнения можно объединять в цепочку: `0 < qty <= 10`
означает то же, что `0 < qty and qty <= 10`. Проверка вхождения пишется через `in`:
`if category in {"овощи", "фрукты"}:`.

## Логические операторы и истинность

Операторы `and`, `or` и `not` вычисляются «лениво»: `and` не смотрит на правую часть, если левая ложна, а `or` —
если левая истинна. Это защищает от ошибок:

```python
qty = 0
if qty != 0 and 500 / qty > 100:
    print("Дорого за штуку")
# деления на ноль не будет: правая часть не вычисляется
```

В условии можно использовать любое значение, не только `True` и `False`. Ложными считаются `False`, `None`, `0`,
`0.0`, пустая строка `""`, пустые список `[]`, кортеж `()`, словарь `{}` и множество `set()`. Всё остальное
истинно, в том числе строка `"0"` и строка из одного пробела.

```python
basket = []
if not basket:
    print("Корзина пуста")
```

## Цикл for

`for` по очереди берёт элементы любой последовательности: списка, строки, словаря, строк файла.

```python
prices = [89.9, 54.0, 412.5, 79.9]
total = 0.0
for price in prices:
    total += price
print(round(total, 2))  # 636.3
```

`range(start, stop, step)` выдаёт числа от `start` до `stop`, **не включая** `stop`: `range(5)` — это 0, 1, 2, 3, 4,
а `range(1, 10, 2)` — 1, 3, 5, 7, 9.

`enumerate` добавляет к элементу его номер, `zip` перебирает несколько последовательностей параллельно:

```python
items = ["молоко", "хлеб", "сыр"]
prices = [89.9, 54.0, 412.5]

for i, item in enumerate(items, start=1):
    print(i, item)              # 1 молоко, 2 хлеб, 3 сыр

for item, price in zip(items, prices):
    print(f"{item}: {price} руб.")
```

`zip` молча останавливается на самой короткой последовательности. С Python 3.10 можно написать
`zip(items, prices, strict=True)`, и при разной длине будет `ValueError`. Словарь перебирают парами через
`.items()`: `for name, price in prices_dict.items():`.

## Подсчёт по группам с помощью словаря

Самый полезный для анализа данных шаблон — накопить суммы по ключу:

```python
purchases = [("молочное", 179.8), ("выпечка", 54.0), ("молочное", 412.5)]

by_category = {}
for category, amount in purchases:
    by_category[category] = by_category.get(category, 0) + amount

print(by_category)  # {'молочное': 592.3, 'выпечка': 54.0}
```

`dict.get(key, 0)` возвращает 0, если ключа ещё нет, поэтому `KeyError` не возникает. Именно этот шаблон нужен
в hw1 для сумм по категориям и магазинам, а в модуле 2 то же самое одной строкой делает `groupby` (L2.3).

## Цикл while, break и continue

`while` повторяет тело, пока условие истинно. Внутри обязательно должно меняться что-то, от чего зависит условие,
иначе цикл не закончится.

```python
balance = 1000
day = 0
while balance > 0:
    balance -= 150
    day += 1
print(day)  # 7
```

`continue` сразу переходит к следующему шагу цикла, `break` завершает цикл целиком:

```python
values = ["89.9", "", "54", "стоп", "412.5"]
total = 0.0
for value in values:
    if value == "":
        continue        # пропускаем пустое значение
    if value == "стоп":
        break           # дальше не читаем
    total += float(value)
print(total)  # 143.9
```

## Генераторы списков

Короткая запись «пройти по списку, отобрать и преобразовать»:

```python
prices = [89.9, 54.0, 412.5, 79.9]
expensive = [p for p in prices if p > 80]
discounted = [round(p * 0.9, 2) for p in prices]
print(expensive)   # [89.9, 412.5]
print(discounted)  # [80.91, 48.6, 371.25, 71.91]
```

Генератор списка всегда можно переписать обычным циклом с `append`. Если выражение не помещается в строку или в нём
больше одного условия, обычный цикл читается лучше.

## Частые ошибки

- **`=` вместо `==`** в условии: `if total = 100:` даёт `SyntaxError` (Python подсказывает: «Maybe you meant '=='»).
- **Забытое двоеточие** после `if`, `for`, `while`: `SyntaxError: expected ':'`.
- **Отступы**: лишний или недостающий пробел даёт `IndentationError`, смесь табуляций и пробелов — `TabError`.
- **`x == 1 or 2`** всегда истинно, потому что `2` — истинное значение. Правильно: `x == 1 or x == 2`
  или `x in (1, 2)`.
- **Ошибка на единицу в `range`**: `range(1, 10)` не включает 10.
- **Обнуление накопителя внутри цикла**: `total = 0` должно стоять до `for`, иначе в конце останется только
  последнее значение.
- **Удаление элементов из списка во время его перебора**: часть элементов пропускается. Соберите новый список
  генератором: `rows = [r for r in rows if r != ""]`.
- **Бесконечный `while`**: условие никогда не становится ложным. В Colab остановите ячейку кнопкой остановки
  и проверьте, меняется ли переменная из условия.

## Для продвинутых

- У `for` и `while` есть ветка `else`: она выполняется, если цикл закончился без `break`. Удобно для поиска.
- Структурное сопоставление `match`/`case` (Python 3.10+): https://peps.python.org/pep-0636/
- Генераторы словарей и множеств (`{k: v for ...}`, `{x for ...}`) и генераторные выражения без лишнего списка
  в памяти: `sum(p for p in prices if p > 80)`.
- Модуль `collections`: `Counter` для подсчёта и `defaultdict` вместо `dict.get`:
  https://docs.python.org/3/library/collections.html
- Оператор `:=` («морж», Python 3.8+) позволяет присвоить значение прямо в условии `while`.
- Циклы Python по строкам таблицы медленные. В pandas и NumPy (модуль 2, L2.1-L2.3) те же расчёты делают
  векторизованными операциями без явного цикла.
- Официальный учебник по управлению потоком: https://docs.python.org/3/tutorial/controlflow.html
