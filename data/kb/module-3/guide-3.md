# Методичка к ДЗ hw3 «Дашборд по продажам»

## Коротко о задании

- Модуль 3 «Визуализация» (30 ноября - 13 декабря 2026), задание hw3 «Дашборд по продажам».
- Дедлайн: **13.12.2026 23:59 МСК**.
- Оценка: 0-10 баллов по критериям ниже; итог «принято» или «на доработку» выставляет преподаватель.
- Формат сдачи: ссылка на Google Colab или файл `.ipynb` в LMS.
- Опорные лекции: L3.1 «Matplotlib: основы графиков», L3.2 «Seaborn и выбор типа графика»,
  L3.3 «Как рассказать историю данными». Подготовка данных опирается на модуль 2 (L2.1-L2.3).

## Цель ДЗ

Собрать из сырых данных о заказах дашборд из четырёх графиков на одной картинке и сформулировать 3-5 выводов
для владельца магазина. В задании тренируются подготовка данных в pandas, построение графиков в Matplotlib
и seaborn, выбор типа графика под вопрос, заголовки-выводы и честное оформление.

Сценарий: вы аналитик вымышленного интернет-магазина товаров для дома «Полка». Владелица магазина хочет понять
итоги 2025 года: как менялась выручка по месяцам, какие категории и каналы продаж приносят деньги и какие заказы
типичны.

## Данные

Файл `hw3_sales.csv` прикреплён к заданию hw3 в LMS. Данные вымышленные: 4 800 заказов с 01.01.2025
по 31.12.2025, разделитель — запятая, кодировка UTF-8. Одна строка — один заказ.

| Колонка | Тип | Описание |
|---|---|---|
| `order_id` | целое | номер заказа, уникален |
| `order_date` | дата `ГГГГ-ММ-ДД` | дата оформления заказа |
| `city` | строка | Москва, Санкт-Петербург, Казань, Екатеринбург, Новосибирск |
| `channel` | строка | канал продаж: `site` (сайт), `app` (приложение), `marketplace` (маркетплейс) |
| `category` | строка | категория товара: Кухня, Текстиль, Декор, Хранение |
| `quantity` | целое | количество единиц товара, от 1 до 10 |
| `unit_price` | число | цена за единицу до скидки, руб. |
| `discount` | число | скидка как доля от 0 до 0.3 (0.15 означает 15%) |
| `customer_type` | строка | `new` — новый покупатель, `returning` — повторный |
| `rating` | число | оценка заказа от 1 до 5; пусто, если покупатель не поставил оценку |

Первые строки файла:

```csv
order_id,order_date,city,channel,category,quantity,unit_price,discount,customer_type,rating
100001,2025-01-03,Москва,site,Кухня,2,1490,0.0,new,5
100002,2025-01-03,Казань,marketplace,Текстиль,1,2390,0.1,new,
100003,2025-01-04,Санкт-Петербург,app,Декор,3,690,0.05,returning,4
100004,2025-01-04,Москва,app,Хранение,4,450,0.0,returning,5
100005,2025-01-05,Новосибирск,site,Кухня,1,3290,0.15,new,3
```

Особенности данных:

- Колонки выручки нет, её нужно посчитать: `revenue = quantity * unit_price * (1 - discount)`.
- В `rating` около 10% пустых значений. Они не мешают считать выручку, поэтому строки целиком не удаляйте.
- `order_date` без параметра `parse_dates` читается как строка, и с датами по ней не поработать.

## Шаги

1. **Создайте блокнот** в Google Colab или Jupyter и загрузите файл. В Colab: панель «Файлы» слева → загрузка
   в сеансовое хранилище, или код `from google.colab import files; files.upload()`.
2. **Прочитайте и проверьте данные** (лекции L2.1 и L2.2):

   ```python
   import matplotlib.pyplot as plt
   import pandas as pd
   import seaborn as sns

   df = pd.read_csv("hw3_sales.csv", parse_dates=["order_date"])
   df.info()
   print(df.isna().sum())
   print("Дубли order_id:", df["order_id"].duplicated().sum())

   df["revenue"] = df["quantity"] * df["unit_price"] * (1 - df["discount"])
   df["month"] = df["order_date"].dt.to_period("M").dt.to_timestamp()  # первый день месяца
   ```

3. **Посчитайте ключевые числа** (лекция L2.3): общая выручка, число заказов, средний чек, доля выручки каждой
   категории и канала, доля повторных покупателей. Выведите их в ячейке — они понадобятся для заголовков и выводов.
4. **Постройте четыре графика**, каждый отвечает на свой вопрос (выбор типа — таблица в L3.2):
   - Г1. Как менялась выручка по месяцам? — линия.
   - Г2. Какие категории дают больше выручки? — горизонтальные столбцы по убыванию, с подписями значений.
   - Г3. Как распределена выручка по каналам продаж? — столбцы по каналам или линии по каналам по месяцам.
   - Г4. Какие заказы типичны? — гистограмма суммы заказа или «ящик с усами» по каналам.
5. **Соберите дашборд**: все четыре графика на одной фигуре 2×2 с общим заголовком-выводом, сохраните PNG
   и покажите фигуру в блокноте. Шаблон можно взять за основу:

   ```python
   monthly = df.groupby("month")["revenue"].sum() / 1000  # тыс. руб.

   fig, axes = plt.subplots(2, 2, figsize=(14, 9), layout="constrained")
   axes[0, 0].plot(monthly.index, monthly.values, marker="o")
   axes[0, 0].set(title="Заголовок-вывод для Г1", ylabel="Выручка, тыс. руб.")
   # axes[0, 1] — Г2 категории, axes[1, 0] — Г3 каналы, axes[1, 1] — Г4 распределение
   fig.suptitle("Магазин «Полка», 2025: главный вывод", fontsize=16)
   fig.savefig("dashboard_hw3.png", dpi=150, bbox_inches="tight")
   plt.show()
   ```

6. **Напишите выводы** в текстовой ячейке «Выводы»: 3-5 пунктов. В каждом — число из данных и ссылка на график,
   например «Категория X даёт N% выручки (Г2)». Добавьте одну рекомендацию для владелицы магазина и отделите
   гипотезы от фактов (лекция L3.3).
7. **Проверьте блокнот с нуля**: в Colab — меню «Среда выполнения» (Runtime) → перезапуск сеанса и выполнение всех
   ячеек; в JupyterLab — Kernel → Restart Kernel and Run All Cells. Блокнот должен выполниться без ошибок,
   а графики — остаться видимыми в сохранённом файле.

## Критерии оценки

Максимум 10 баллов.

| Критерий | Баллы | Что проверяется |

| 1. Данные и воспроизводимость | 2 | блокнот выполняется с нуля без ошибок; `order_date` в формате даты; выручка посчитана с учётом скидки; пропуски проверены, строки с пустым `rating` не удалены при подсчёте выручки |
| 2. Выбор типов графиков | 2 | для каждого из четырёх вопросов выбран подходящий тип: линия для динамики, столбцы для сравнения категорий, гистограмма или «ящик с усами» для распределения |
| 3. Корректность графиков | 2 | агрегаты верны (сумма, где нужна выручка, а не среднее); месяцы идут по порядку; столбцы начинаются с нуля; категории отсортированы |
| 4. Оформление | 2 | заголовки-выводы; подписи осей с единицами измерения; одна категория или канал — один цвет на всех графиках; подписи не наезжают друг на друга |
| 5. Дашборд и выводы | 2 | четыре графика на одной фигуре с общим заголовком, PNG сохранён; 3-5 выводов с числами из данных и ссылками на графики, есть рекомендация |

## Частые ошибки

- Выручка посчитана без скидки или скидка подставлена в процентах: `* (1 - 15)` вместо `* (1 - 0.15)`.
- `df.dropna()` по всей таблице: пропадают заказы без оценки, и выручка занижена примерно на десятую часть.
- `sns.barplot` без `estimator="sum"` показывает средний чек вместо выручки (лекция L3.2).
- Месяцы на графике идут по алфавиту, потому что группировка шла по строковым названиям месяцев.
- `plt.savefig()` вызван после `plt.show()` или в другой ячейке — в файле пустая картинка. Сохраняйте через
  `fig.savefig(...)` до показа (лекция L3.1).
- Заголовки «График 1», подписи осей без единиц измерения.
- Один и тот же канал на разных графиках раскрашен разными цветами.
- Выводы без чисел, или в них причины, которых нет в данных (например, «из-за рекламы» — данных о рекламе нет).
- Ссылка на Colab закрыта: преподаватель видит «Нет доступа». Проверяйте ссылку в окне инкогнито.
- Ячейки выполнялись вразнобой, и с нуля блокнот падает с ошибкой.
