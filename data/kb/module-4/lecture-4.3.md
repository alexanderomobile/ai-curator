# Защита проекта

Защита итогового проекта проходит 26-27 декабря 2026 года по записи, время московское. Слоты защиты публикуются
в расписании LMS. Защищённый итоговый проект — обязательное условие сертификата: кроме него нужно, чтобы были
приняты минимум 3 из 4 работ (hw1-hw3 и итоговый проект). В лекции разберём, как построить рассказ, подготовить
графики и ноутбук к показу и спокойно ответить на вопросы.

## Как устроена защита

- Вы показываете ноутбук или слайды, рассказываете о проекте и отвечаете на вопросы преподавателя.
- Сам проект сдаётся в LMS в задании final «Итоговый проект»: ссылка на Google Colab или файл .ipynb.
  Дедлайн сдачи — 27.12.2026 23:59 МСК. Удобнее сдать работу до своего слота защиты, чтобы показывать
  ту же версию, которую будет читать преподаватель.
- Решение «принято» или «на доработку» и баллы 0-10 по критериям из методички guide-4 выставляет только
  преподаватель. ИИ-куратор оценок не ставит и сроки не меняет.
- Если проект отправлен «на доработку», на исправление есть 5 дней.

## Структура выступления

Точную длительность слота смотрите в расписании LMS. Внутри слота удобно держать такие пропорции:

| Часть | Доля времени | Что сказать |
|---|---|---|
| Вопрос | 10% | Что выяснили и кому это полезно |
| Данные и подготовка | 15% | Источник, период, сколько строк, что удалили и почему |
| Результаты | 50% | 2-3 ключевых графика, у каждого один вывод с числом |
| Ограничения | 10% | Чего данные не показывают |
| Выводы и что дальше | 15% | Ответ на вопрос и следующий шаг |

Главное правило: **один график — одна мысль**. Код на защите не прокручивают строка за строкой: показывают
результат, а код открывают, если об этом спросят.

## Готовим графики для экрана

На экране мелкий шрифт не читается. В seaborn есть контекст `talk`, который увеличивает подписи, а цвет
лучше тратить только на главное (приём из L3.3):

```python
import matplotlib.pyplot as plt
import seaborn as sns

sns.set_theme(style="whitegrid", context="talk")  # крупные подписи для показа

revenue = (
    trips.groupby("district")["price_rub"].sum()
    .sort_values(ascending=False) / 1000
)
colors = ["tab:blue"] + ["lightgray"] * (len(revenue) - 1)

fig, ax = plt.subplots(figsize=(10, 5))
bars = ax.bar(revenue.index, revenue.to_numpy(), color=colors)
ax.bar_label(bars, fmt="%.0f")
ax.set(
    title=f"{revenue.index[0]} район даёт больше всего выручки",
    ylabel="Выручка за сезон, тыс. руб.",
)
fig.tight_layout()
fig.savefig("slide_revenue.png", dpi=200, bbox_inches="tight")
plt.show()
```

Здесь `trips` — очищенная таблица из L4.2. Файл PNG с `dpi=200` можно вставить в слайд, а
`bbox_inches="tight"` обрезает лишние поля.

## Проверяем ноутбук перед защитой

1. Перезапустите ядро и выполните все ячейки: в Colab меню Runtime («Среда выполнения») → Restart session and
   run all, в JupyterLab Kernel → Restart Kernel and Run All Cells. Ошибок быть не должно.
2. Откройте ссылку на Colab в окне инкогнито. Если видите запрос доступа, откройте его кнопкой Share
   («Поделиться»): доступ «все, у кого есть ссылка», роль «читатель».
3. Проверьте, что данные загружаются не с вашего диска `C:\...`, а из файла рядом с ноутбуком или по ссылке.
   Файлы, загруженные в панель «Файлы» Colab, пропадают, когда среда выполнения отключается.

Понятная ошибка в начале ноутбука лучше длинной трассировки посередине:

```python
from pathlib import Path

DATA_PATH = Path("velograd_trips_2026.csv")
if not DATA_PATH.exists():
    raise FileNotFoundError(
        f"Нет файла {DATA_PATH}. В Colab загрузите его через панель «Файлы» слева."
    )
```

## Вопросы, к которым стоит подготовиться

| Вопрос | Что проверяют | Как ответить |
|---|---|---|
| «Почему этот датасет и вопрос?» | Осознанность выбора | Кому полезен ответ и почему данные подходят |
| «Как обработали пропуски и выбросы?» | Качество подготовки | Сколько строк, какое правило, как это повлияло на вывод |
| «Почему такой тип графика?» | Выбор визуализации | Что сравниваем: категории, динамику, распределение (L3.2) |
| «Это причина или совпадение?» | Понимание ограничений | Это связь; чтобы говорить о причине, нужен эксперимент или больше данных |
| «Что изменится, если поменять порог очистки?» | Устойчивость вывода | Покажите расчёт с другим порогом или честно скажите, как это проверить |

Если ответа нет, так и скажите: «Не проверял, но проверил бы так...». Это засчитывается лучше, чем уверенная
догадка. Замечания преподавателя — не спор, а список для доработки.

## Частые ошибки

- **Чтение ноутбука вслух** и прокрутка кода вместо рассказа о результатах.
- **Десять графиков без выводов.** Лучше три, но с ясной мыслью у каждого.
- **Выводы оставлены на конец и не уместились во время.** Главный ответ скажите в первой минуте.
- **Ноутбук падает при перезапуске** или файл данных пропал из Colab.
- **Ссылка без доступа.** Преподаватель не может открыть работу.
- **Нет записи на слот.** Запишитесь заранее: защита идёт только 26 и 27 декабря.

## Для продвинутых

- Подготовьте приложение: раздел с деталями метода, к которому можно перейти по вопросу, не загромождая рассказ.

  ячейки задаётся в её метаданных (в JupyterLab — поле Slide Type в панели свойств ячейки).

  и покажите, что знак и порядок эффекта не меняются.
