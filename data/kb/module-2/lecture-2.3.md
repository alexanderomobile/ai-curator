# Группировка и агрегация

Большинство вопросов к данным звучат как «сколько по каждому...»: выручка по городам, число заказов по дням,
средний чек по категориям. В pandas на них отвечает `groupby`. Примеры проверены на Python 3.12 и pandas 2.x.
В учебной таблице одна строка — одна позиция заказа, поэтому у одного заказа может быть несколько строк.

```python
import pandas as pd

sales = pd.DataFrame({
    "order_id": [1, 1, 2, 3, 3, 3, 4, 5],
    "date": pd.to_datetime(["2026-11-16", "2026-11-16", "2026-11-16", "2026-11-17",
                            "2026-11-17", "2026-11-17", "2026-11-18", "2026-11-18"]),
    "city": ["Казань", "Казань", "Пермь", "Казань", "Казань", "Казань", "Пермь", "Самара"],
    "category": ["бумага", "письмо", "письмо", "сумки", "бумага", "письмо", "бумага", "сумки"],
    "revenue": [500, 450, 225, 3200, 250, 90, 750, 3200],
})
```

## Как работает groupby

Группировка проходит в три шага, которые в документации pandas называют split-apply-combine: таблица делится
на группы по значению ключа, к каждой группе применяется функция, результаты собираются в новую таблицу.

```python
by_city = sales.groupby("city")["revenue"].sum()
print(by_city)
# city
# Казань    4490
# Пермь      975
# Самара    3200
# Name: revenue, dtype: int64
```

Сам вызов `sales.groupby("city")` ещё ничего не считает: он возвращает объект `DataFrameGroupBy`, который помнит,
какие строки попали в какую группу. Расчёт происходит, когда к нему применяют функцию: `sum()`, `mean()`, `agg()`.
Заглянуть в группы до расчёта помогают `sales.groupby("city").ngroups` (сколько групп, здесь 3) и
`sales.groupby("city").get_group("Пермь")` (строки одной группы).

Результат — `Series`, где индекс — значения ключа. Группы по умолчанию упорядочены по ключу (`sort=True`); чтобы
получить рейтинг, отсортируйте по значению: `by_city.sort_values(ascending=False)`. Типичная цепочка анализа
выглядит так: отфильтровать строки, сгруппировать, посчитать метрики, отсортировать результат и проверить его
на одной группе вручную.

Если ключей несколько, индекс становится многоуровневым (`MultiIndex`). Чтобы ключи остались обычными столбцами,
укажите `as_index=False` или вызовите `reset_index()`:

```python
print(sales.groupby(["city", "category"])["revenue"].sum())   # индекс из двух уровней

table = sales.groupby("city", as_index=False)["revenue"].sum()
print(table.columns.tolist())   # ['city', 'revenue']
```

## Несколько метрик: agg

Именованная агрегация задаёт каждую метрику в виде `имя=(столбец, функция)`:

```python
summary = sales.groupby("city").agg(
    revenue=("revenue", "sum"),
    lines=("revenue", "size"),
    orders=("order_id", "nunique"),
)
print(summary)
#         revenue  lines  orders
# city
# Казань     4490      5       2
# Пермь       975      2       2
# Самара     3200      1       1
```

Функции передают строкой: `"sum"`, `"mean"`, `"median"`, `"min"`, `"max"`, `"count"`, `"size"`, `"nunique"`,
`"first"`, `"last"`. Разница между тремя «счётчиками»:

- `size` — сколько строк в группе, пропуски тоже считаются;
- `count` — сколько непустых значений в столбце;
- `nunique` — сколько разных значений (здесь — разных заказов).

Можно написать и `agg(["sum", "mean"])`, но тогда у заголовков столбцов появятся два уровня, и обращаться к ним
неудобно. Именованная агрегация сразу даёт понятные имена.

## Среднее по строкам и среднее по заказам

Средний чек — это средняя сумма заказа, а не средняя строка. Если у заказа несколько строк, сначала сложите их
внутри заказа, а потом усредняйте по заказам:

```python
checks = sales.groupby(["city", "order_id"], as_index=False)["revenue"].sum()
avg_check = checks.groupby("city")["revenue"].mean()
print(avg_check.to_dict())                              # {'Казань': 2245.0, 'Пермь': 487.5, 'Самара': 3200.0}
print(sales.groupby("city")["revenue"].mean()["Казань"])  # 898.0 — средняя строка, а не средний чек
```

## Сводная таблица

`pivot_table` раскладывает один ключ по строкам, другой — по столбцам:

```python
pivot = sales.pivot_table(index="city", columns="category", values="revenue",
                          aggfunc="sum", fill_value=0, margins=True, margins_name="Итого")
print(pivot)
# category  бумага  письмо  сумки  Итого
# city
# Казань       750     540   3200   4490
# Пермь        750     225      0    975
# Самара         0       0   3200   3200
# Итого       1500     765   6400   8665
```

`fill_value=0` ставит ноль там, где продаж не было, `margins=True` добавляет итоги. Результат — обычный `DataFrame`:
к нему применимы фильтры и сортировка из L2.2, а сохранить его можно методом `to_csv`. Для подсчёта количества строк
в каждой паре значений есть `pd.crosstab(sales["city"], sales["category"])`.

## Группировка по датам и transform

Ключом может быть не только столбец, но и вычисленный признак, например день недели (0 — понедельник):

```python
by_weekday = sales.groupby(sales["date"].dt.day_of_week)["revenue"].sum()
print(by_weekday.to_dict())   # {0: 1175, 1: 3540, 2: 3950}
```

`dt.day_name()` возвращает английские названия (`'Monday'`); русские удобнее получить словарём через `map`.

`transform` возвращает результат той же длины, что и исходная таблица: итог группы записывается в каждую её строку.
Так считают долю строки в итоге группы:

```python
sales["city_total"] = sales.groupby("city")["revenue"].transform("sum")
sales["share"] = (sales["revenue"] / sales["city_total"]).round(3)
print(sales["share"].head(2).tolist())   # [0.111, 0.1]
```

## Частые ошибки

- **`sales.groupby("city").mean()` падает с `TypeError`.** С pandas 2.0 у `mean` по умолчанию `numeric_only=False`,
  и текстовый столбец `category` вызывает ошибку `agg function failed`. Выберите столбец
  (`groupby("city")["revenue"].mean()`) или передайте `numeric_only=True`.
- **Путают `count` и `size`.** Для числа заказов нужен `nunique` по номеру заказа, а не число строк.
- **Пропали строки с пустым ключом.** `groupby` по умолчанию отбрасывает группы с `NaN` в ключе (`dropna=True`).
  Если они важны, укажите `dropna=False` или заполните ключ заранее.
- **Среднее средних.** Среднее по группам средних не равно общему среднему, если группы разного размера.
  Считайте от сумм и количеств.
- **`KeyError: 'city'` после группировки.** Ключ ушёл в индекс; используйте `reset_index()` или `as_index=False`.
- **«Топ» без сортировки.** Результат `groupby` упорядочен по ключу, а не по значению.

## Если сложно

Повторите эти темы:

- L2.1 «Series и DataFrame, чтение CSV» — индекс и `Series`: результат `groupby` — это `Series` с ключами в индексе.
- L2.2 «Фильтрация, сортировка, пропуски» — отбор строк до группировки и `sort_values` после неё.
- L1.3 «Функции и модули» — функции как аргументы: в `agg` можно передать свою функцию, например
  `agg(spread=("revenue", lambda s: s.max() - s.min()))`.

Аналогия: `groupby` с `agg` и `pivot_table` делают то же, что сводная таблица в Excel или Google Таблицах. Приём
проверки: возьмите одну группу (`sales[sales["city"] == "Казань"]`), посчитайте итог вручную и сравните
с результатом `groupby`.

## Для продвинутых

- **`filter`** оставляет группы целиком по условию:
  `sales.groupby("city").filter(lambda g: g["order_id"].nunique() >= 2)`.
- **`apply` медленнее** встроенных `agg` и `transform`: он вызывает Python-функцию для каждой группы. Начинайте
  со встроенных функций.
- **Категориальные ключи.** С pandas 2.1 группировка по `category` без `observed` выдаёт `FutureWarning`; передавайте
  `observed=True` явно (в pandas 3.0 это значение по умолчанию).
- **Время:** `sales.resample("W", on="date")["revenue"].sum()` или `pd.Grouper(key="date", freq="W")`. С pandas 2.2
  конец месяца обозначают `"ME"`, прежний `"M"` устарел.
- **Форма таблицы:** `melt`, `pivot`, `stack` и `unstack`.
- Результат группировки сразу рисуется: `by_city.plot.bar()` — это тема L3.1 «Matplotlib: основы графиков».
- Документация: разделы User Guide «Group by: split-apply-combine» и «Reshaping and pivot tables» на pandas.pydata.org.
