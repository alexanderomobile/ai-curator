# Фильтрация, сортировка, пропуски

Таблица прочитана (L2.1 «Series и DataFrame, чтение CSV»), и почти всегда дальше нужно три вещи: отобрать строки
по условию, упорядочить их и разобраться с пропусками. Примеры проверены на Python 3.12 и pandas 2.x. В учебной
таблице есть пропуски: город не указан в заказе 1003, количество — в заказе 1004, цена — в заказе 1007.

```python
import numpy as np
import pandas as pd

orders = pd.DataFrame({
    "order_id": [1001, 1002, 1003, 1004, 1005, 1006, 1007],
    "city": ["Казань", "Пермь", None, "Самара", "Пермь", "Казань", "Самара"],
    "item": ["блокнот", "ручка", "рюкзак", "ручка", "блокнот", "пенал", "рюкзак"],
    "qty": [2, 10, 1, np.nan, 3, 4, 1],
    "price": [250, 45, 3200, 45, 250, 390, np.nan],
})
```

## Булевы маски

Сравнение столбца со значением даёт `Series` из `True` и `False` той же длины — маску. Таблица, к которой обратились
с маской в квадратных скобках, оставляет только строки с `True`.

```python
mask = orders["qty"] >= 3
print(mask.tolist())                      # [False, True, False, False, True, True, False]
print(orders[mask]["order_id"].tolist())  # [1002, 1005, 1006]
```

Сравнения `>`, `>=`, `<`, `<=` и `==` с пропуском дают `False` (а `!=` — `True`), поэтому заказ 1004 без количества
в результат не попал.

Несколько условий объединяют операторами `&` (и), `|` (или), `~` (не), и каждое условие берут в круглые скобки:

```python
kazan_big = orders[(orders["city"] == "Казань") & (orders["qty"] >= 3)]
print(kazan_big["order_id"].tolist())     # [1006]

not_perm = orders[~(orders["city"] == "Пермь")]
print(len(not_perm))                      # 5 — строка без города тоже попала
```

Полезные готовые проверки:

```python
print(orders[orders["item"].isin(["ручка", "пенал"])]["order_id"].tolist())   # [1002, 1004, 1006]
print(orders[orders["price"].between(100, 500)]["order_id"].tolist())         # [1001, 1005, 1006]
print(orders[orders["city"].str.contains("ам", na=False)]["order_id"].tolist())  # [1004, 1007]
print(orders.query("qty >= 3 and city == 'Пермь'")["order_id"].tolist())      # [1002, 1005]
```

`isin` проверяет вхождение в список, `between` включает обе границы, `str.contains` ищет подстроку в тексте,
`query` принимает условие строкой. Отбор строк и выбор столбцов делают одной операцией через `loc`, через него же
меняют значения по условию:

```python
print(orders.loc[orders["qty"] >= 3, ["order_id", "item"]])

fixed = orders.copy()
fixed.loc[fixed["item"] == "ручка", "price"] = 50   # правильное изменение по условию
```

## Сортировка

```python
by_price = orders.sort_values("price", ascending=False)                 # дорогие сверху
by_city = orders.sort_values(["city", "qty"], ascending=[True, False])  # город, внутри — количество
top3 = orders.nlargest(3, "qty")
print(top3["order_id"].tolist())                                        # [1002, 1006, 1005]
```

Что важно знать:

- `sort_values` возвращает новую таблицу, исходная остаётся прежней.
- Пропуски по умолчанию уходят в конец при любом направлении (`na_position="last"`).
- Строки сохраняют старые метки индекса. Чтобы пронумеровать заново, добавьте `.reset_index(drop=True)`.
- `sort_index()` сортирует по индексу, `nlargest` и `nsmallest` быстро дают «топ-N».

## Пропуски

Пропуск в числовом столбце pandas показывает как `NaN`, в датах — как `NaT`; в текстовом столбце типа `object`
может храниться `None` или `NaN`. Метод `isna()` находит пропуски любого вида.

```python
print(orders.isna().sum())            # пропусков в столбцах: city 1, qty 1, price 1, остальные 0
print(orders.isna().mean().round(2))  # доля пропусков: 0.14 у city, qty, price
```

С пропусками поступают одним из трёх способов.

1. **Удалить строки.** `orders.dropna(subset=["qty"])` удаляет только строки без количества. `dropna()` без
   аргументов удаляет строку с пропуском в любом столбце, и так легко потерять полезные данные. Есть варианты
   `how="all"` (удалить, только если пусто всё) и `thresh=` (минимум непустых значений в строке).
2. **Заполнить.** Словарь задаёт значение для каждого столбца: `orders.fillna({"city": "не указан"})`. Числа
   заполняют медианой (`orders["qty"].fillna(orders["qty"].median())`), ряды по времени — предыдущим значением
   (`ffill()`).
3. **Оставить.** `sum()`, `mean()` и другие агрегаты по умолчанию пропуски пропускают (`skipna=True`).

```python
clean = orders.dropna(subset=["qty"])
clean = clean.fillna({"city": "не указан"})
print(len(clean), clean["city"].isna().sum())  # 6 0
print(orders["price"].mean())                  # 696.6666666666666 — среднее по 6 известным ценам
```

Способ выбирают по смыслу столбца и записывают в ноутбуке: сколько строк удалено и почему. Ноль — не нейтральное
значение: цена, заполненная нулём, занизит среднюю цену.

Рядом с пропусками стоят дубли — повторы одной и той же строки. `orders.duplicated().sum()` считает полные
повторы, `orders.drop_duplicates()` их убирает, а `subset=["order_id"]` сравнивает строки только по номеру заказа.

## Частые ошибки

- **`and` / `or` вместо `&` / `|`.** Python не может свести столбец к одному `True` или `False`:
  `ValueError: The truth value of a Series is ambiguous`.
- **Условия без скобок.** В записи `orders["qty"] > 2 & orders["city"] == "Казань"` оператор `&` выполняется
  раньше сравнений, и вместо маски получается `TypeError`. Каждое условие — в своих скобках.
- **`orders[orders["qty"] == np.nan]` всегда пуст.** `NaN` не равен ничему, даже самому себе. Используйте `isna()`
  и `notna()`.
- **Результат не сохранён.** `orders.dropna()` без присваивания не меняет таблицу. А `orders = orders.dropna(inplace=True)`
  записывает в `orders` значение `None`: с `inplace=True` методы ничего не возвращают.
- **Цепочка присваиваний.** `orders[orders["qty"] > 3]["price"] = 0` меняет временную копию, исходная таблица
  остаётся прежней, а pandas 2.x выводит `SettingWithCopyWarning`. Правильно — `orders.loc[маска, "price"] = 0`.
  Если отфильтрованную часть потом меняете, сделайте её копией: `subset = orders[mask].copy()`.
- **`str.contains` по столбцу с пропусками.** Маска с `NaN` вызывает `ValueError: Cannot mask with non-boolean array
  containing NA / NaN values`. Добавьте `na=False`.
- **`fillna(0)` там, где ноль бессмыслен.** Средние и суммы искажаются незаметно.

## Для продвинутых

- **`query` с переменными:** `limit = 3; orders.query("qty >= @limit")`.
- **Новый столбец по условию:** `np.where(orders["qty"] >= 3, "крупный", "обычный")`, методы `where` и `mask`.
- **Nullable-типы** `Int64`, `boolean`, `string` и значение `pd.NA`: целые числа с пропусками не превращаются
  во `float`, а логика сравнений с пропуском становится трёхзначной.
- **`interpolate()`** заполняет пропуски во временных рядах по соседним значениям.
- **Copy-on-Write.** В pandas 2.x режим включают `pd.set_option("mode.copy_on_write", True)`; в pandas 3.0 он
  работает по умолчанию, и цепочка присваиваний исходную таблицу не меняет никогда.
- **Стабильная сортировка.** При сортировке по одному столбцу по умолчанию используется quicksort, и порядок
  равных строк не гарантирован; `kind="stable"` его сохраняет.
