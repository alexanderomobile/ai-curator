# Series и DataFrame, чтение CSV

В модуле 1 вы хранили данные в списках и словарях и считали итоги циклами. Для таблицы на тысячи строк это
неудобно: приходится помнить, какой элемент к какому столбцу относится, а каждый подсчёт превращается в цикл.
Библиотека pandas хранит данные как таблицу с названиями столбцов и считает по столбцу целиком одной командой.
Примеры лекции проверены на Python 3.12 и pandas 2.x. В Google Colab pandas уже установлен, локально его ставят
командой `pip install pandas`.

Библиотеку принято импортировать под коротким именем `pd`:

```python
import pandas as pd
```

## Series: столбец с подписями

`Series` — одномерный набор значений, у каждого значения есть метка (индекс). Если индекс не указать, pandas
пронумерует элементы с нуля: 0, 1, 2 и так далее.

```python
prices = pd.Series([250, 45, 3200], index=["блокнот", "ручка", "рюкзак"], name="price")

print(prices["ручка"])   # 45 — доступ по метке
print(prices.mean())     # 1165.0 — среднее без цикла
print(prices * 2)        # умножение применяется к каждому элементу
```

Арифметика между двумя `Series` выравнивается по меткам, а не по позициям. Если метка есть только в одной из них,
результат для неё — `NaN` (пропуск, «нет значения»):

```python
stock = pd.Series([10, 3], index=["ручка", "пенал"])
print(prices + stock)
# блокнот     NaN
# пенал       NaN
# ручка      55.0
# рюкзак      NaN
# dtype: float64
```

Числа стали дробными (`float64`), потому что `NaN` в pandas — значение с плавающей точкой.

## DataFrame: таблица из столбцов

`DataFrame` — двумерная таблица. О ней удобно думать как о словаре: ключ — название столбца, значение — `Series`.
Все столбцы делят общий индекс строк.

```python
df = pd.DataFrame({
    "item": ["блокнот", "ручка", "рюкзак"],
    "qty": [2, 10, 1],
    "price": [250, 45, 3200],
})

df["total"] = df["qty"] * df["price"]   # новый столбец из двух существующих
print(df["total"].sum())                # 4150
```

Один столбец `df["qty"]` — это `Series`, а список столбцов `df[["item", "qty"]]` — снова `DataFrame`. Обратите
внимание на двойные квадратные скобки: внешние означают обращение к таблице, внутренние — список названий.

## Чтение CSV

На практике таблицы не набирают вручную, а читают из файла. CSV (comma-separated values) — текстовый формат: одна
строка файла соответствует одной строке таблицы, значения разделены запятой или другим символом. Читает такие файлы
функция `pd.read_csv`. Чтобы пример запускался без файла, данные заданы строкой и обёрнуты в `io.StringIO`; с
настоящим файлом вместо этого указывают путь: `pd.read_csv("orders.csv", sep=";")`.

```python
import io

csv_text = """order_id;date;city;item;qty;price
1001;2026-11-16;Казань;блокнот;2;250
1002;2026-11-16;Пермь;ручка;10;45
1003;2026-11-17;Казань;рюкзак;1;3200
1004;2026-11-18;Самара;ручка;5;45
1005;2026-11-18;Пермь;блокнот;3;250
"""

orders = pd.read_csv(io.StringIO(csv_text), sep=";", parse_dates=["date"])
```

Параметры, которые нужны чаще всего:

| Параметр | Что делает | Пример |
|---|---|---|
| `sep` | разделитель значений (по умолчанию запятая) | `sep=";"` |
| `decimal` | десятичный разделитель (по умолчанию точка) | `decimal=","` |
| `encoding` | кодировка файла (по умолчанию UTF-8) | `encoding="cp1251"` |
| `parse_dates` | какие столбцы прочитать как даты | `parse_dates=["date"]` |
| `usecols` | прочитать только нужные столбцы | `usecols=["date", "qty"]` |
| `dtype` | задать тип столбца явно | `dtype={"order_id": str}` |
| `nrows` | прочитать только первые N строк | `nrows=1000` |

CSV из русской версии Excel обычно разделён точкой с запятой, а дроби в нём записаны через запятую; старые выгрузки
бывают в кодировке Windows-1251 (`cp1251`). Функция умеет читать и по ссылке: `pd.read_csv("https://...")`. В Colab
файл загружают через панель «Файлы» слева. Загруженные файлы живут только в текущем сеансе: после отключения среды
выполнения их нужно загрузить снова.

## Первый осмотр таблицы

Прочитав файл, сразу проверьте, что он прочитался правильно:

```python
print(orders.head(3))           # первые 3 строки (без аргумента — 5)
print(orders.shape)             # (5, 6) — число строк и столбцов
print(orders.columns.tolist())  # ['order_id', 'date', 'city', 'item', 'qty', 'price']
print(orders.dtypes)            # тип каждого столбца
orders.info()                   # типы, число непустых значений, память
print(orders.describe())        # статистика по числовым столбцам и датам
```

На что смотреть: совпадает ли число столбцов с ожидаемым, получили ли числа числовой тип (`int64`, `float64`),
стала ли дата типом `datetime64[ns]`. Текст в pandas 2.x по умолчанию хранится в типе `object`.

`shape` — атрибут, его пишут без скобок, а `head()` и `info()` — методы, их вызывают со скобками. `info()` сама
печатает сводку и возвращает `None`, поэтому `print(orders.info())` выведет в конце лишнюю строку `None`.

## Выбор строк и столбцов: loc и iloc

- `loc` выбирает по меткам индекса и названиям столбцов;
- `iloc` выбирает по номерам позиций, как срез списка.

```python
print(orders.loc[0:2, ["item", "qty"]])      # метки 0, 1, 2 — правая граница включена
print(orders.iloc[0:2, 3:5])                 # позиции 0 и 1, столбцы item и qty — граница не включена
print(orders.loc[orders.index[-1], "city"])  # Пермь — город в последней строке
```

Разница в правой границе — частая причина ошибок «на одну строку».

## Частые ошибки

- **Вся таблица в одном столбце.** Неверный разделитель: файл разделён `;`, а читается с запятой по умолчанию.
  Признак — `orders.shape` показывает один столбец. Решение — `sep=";"`.
- **`UnicodeDecodeError` при чтении.** Файл не в UTF-8; попробуйте `encoding="cp1251"`.
- **Числа прочитались как текст (`object`).** В столбце есть запятые в дробях, пробелы между разрядами или слова
  вроде «нет». Помогают `decimal=","`, `thousands=" "` или `pd.to_numeric(столбец, errors="coerce")`: он превратит
  нечисловые значения в `NaN`.
- **`KeyError` при обращении к столбцу.** Опечатка или лишний пробел в названии. Выведите `orders.columns.tolist()`;
  пробелы по краям убирает `orders.columns = orders.columns.str.strip()`.
- **`df["item", "qty"]` вместо `df[["item", "qty"]]`.** Без внутреннего списка pandas ищет один столбец с именем
  `('item', 'qty')` и падает с `KeyError`.
- **`orders.shape()`** даёт `TypeError: 'tuple' object is not callable`: `shape` — атрибут, а не метод.
- **`FileNotFoundError` в Colab.** Файл не загружен в текущий сеанс или путь указан неверно.

## Для продвинутых

- **Типы и память.** Повторяющиеся строки (города, категории) экономнее хранить в типе `category`:
  `dtype={"city": "category"}`. Сравните `orders.memory_usage(deep=True)` до и после.
- **Большие файлы.** `pd.read_csv(path, chunksize=100_000)` возвращает итератор по частям таблицы: так обрабатывают
  файлы, которые не помещаются в оперативную память.
- **Arrow.** С установленным пакетом `pyarrow` можно читать быстрее (`engine="pyarrow"`) и хранить данные
  в Arrow-типах (`dtype_backend="pyarrow"`, параметр появился в pandas 2.0).
- **Индекс.** `set_index("order_id")` делает столбец индексом, `reset_index()` возвращает его в столбцы;
  многоуровневый индекс встретится в L2.3 «Группировка и агрегация».
