## 3. Вопрос s02

Условия: уровень beginner, студент —, модуль 2; ответ в материалах есть.

> Студент (раньше): Не понимаю, как работает groupby в pandas
> Помощник (раньше): groupby делит таблицу на группы по значениям столбца, а потом к каждой группе применяется функция — например, sum или mean.

**Вопрос:** А как посчитать сразу несколько показателей?

Ожидаемые пункты:
1. после groupby вызывается agg (агрегирование) — с несколькими функциями сразу
2. пример кода: именованная агрегация вида agg(выручка=("столбец", "sum"), ...) или agg(["sum", "mean"])
3. объяснение простыми словами, по шагам — студент начинающий

Запрещено:
1. методы, которых нет в pandas

### Ответ X

Чтобы посчитать несколько показателей сразу, используйте метод `agg` с именованной агрегацией. Это значит, что вы указываете для каждого показателя имя, столбец и функцию, которая к нему применяется.

Вот как это сделать шаг за шагом:

1. Группируйте таблицу по нужному столбцу, например, по городу:
```python
grouped = sales.groupby("city")
```

2. Примените `agg` с несколькими метриками, например, сумму выручки, число строк и число уникальных заказов:
```python
summary = grouped.agg(
    revenue_sum=("revenue", "sum"),    # сумма выручки
    lines_count=("revenue", "size"),  # число строк (позиций заказа)
    orders_count=("order_id", "nunique")  # число уникальных заказов
)
print(summary)
```

3. В результате получите таблицу, где для каждого города посчитаны все эти показатели.

Пример из лекции:

```python
summary = sales.groupby("city").agg(
    revenue=("revenue", "sum"),
    lines=("revenue", "size"),
    orders=("order_id", "nunique"),
)
print(summary)
```

Это выведет:

```
        revenue  lines  orders
city
Казань     4490      5       2
Пермь       975      2       2
Самара     3200      1       1
```

Так вы сразу видите сумму выручки, количество строк и число заказов по каждому городу.

Если что-то непонятно, можно повторить раздел «Если сложно» в лекции L2.3, где есть рекомендации, что повторить для лучшего понимания.

### Ответ Y

Чтобы посчитать несколько показателей сразу, используйте метод `agg` с именованной агрегацией. Например:

```python
summary = df.groupby("city").agg(
    total_revenue=("revenue", "sum"),
    orders_count=("order_id", "nunique"),
    avg_revenue=("revenue", "mean")
)
print(summary)
```

Здесь для каждой группы по столбцу `city` считаются сумма выручки, число уникальных заказов и средняя выручка. Имена показателей (`total_revenue`, `orders_count`, `avg_revenue`) вы задаёте сами.
